# 研究工作流程

以明确的研究问题为起点，按“文献 → 实验 → 证据 → 复现”的顺序建立记录。记录可以反复补充；结论变化时保留原始来源和修订依据。

| 类型 | 建议编号 | 必要关联 |
| --- | --- | --- |
| 文献 | `LIT-001` | DOI、URL 或其他可定位来源；检索日期和筛选理由 |
| 实验 | `EXP-001` | 数据来源、代码版本、环境、参数与结果 |
| 证据 | `EVD-001` | 具体论断及支持或反驳它的文献、实验编号 |
| 复现 | `REP-001` | 对应实验编号、执行步骤及结果差异 |

每个编号在项目内保持唯一。记录放在 `records/literature/`、`records/experiments/`、`records/evidence/` 或 `records/reproductions/`，文件名以编号开头，例如 `LIT-001-paper-title.md`。目录在首次使用时创建。

## 最小闭环

1. 保存检索数据库、关键词、日期及筛选结果。
2. 对选中文献建立记录，区分原文结论与自己的解释。
3. 实验时记录输入、环境、代码版本和预设指标；失败或不一致的结果也要记录。
4. 为关键论断建立证据记录，引用具体文献或实验，标出反例和局限性。
5. 按复现模板重跑实验，比较预期与实际结果，记录差异和待查问题。

记录中不要放访问令牌、个人敏感信息或未经许可分享的数据。对大体积数据保留获取方式、版本、校验值和许可信息。
