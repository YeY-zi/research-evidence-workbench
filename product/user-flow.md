# 用户流程与异常路径

```text
输入研究问题
  ├─ 为空 → 提示输入具体问题
  ├─ 样本外/未匹配 → 明确显示“当前示例资料未找到”；引导改写或自行查阅原文
  └─ 匹配 → 展示人工整理线索、文献元数据、章节定位与原文链接
               ├─ 用户认为无关 → 返回问题，改写或停止
               └─ 用户打开原文核对 → 填写自己的判断与局限
                                      ├─ 判断为空 → 不允许保存
                                      └─ 保存 → 本地卡片列表 → 导出 Markdown / 删除
  任一查询结果 → 用户手动登记自己核对的公开论文标题、HTTPS 链接和原文位置
               ├─ 字段/链接格式错误 → 提示修正；不进入卡片编辑
               └─ 标记为“用户提供、未经系统核验” → 打开原文 → 同上建卡流程
```

三屏[可点击原型](../prototype/index.html)分别表示输入、来源核对和证据卡片；[运行演示](../app/README.md)还支持手动来源分支。选择来源只是创建卡片的前提，不等于来源必然支持用户判断；评测时需人工核查。
