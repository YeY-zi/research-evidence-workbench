# 评价方案 v0.2｜离线结果与待做用户评测

**现状**：已冻结[30 道单人桌面标注题](questions.csv)，运行过[原型基线逐题结果](results-baseline.json)。这只是受控资料上的程序测试，尚无目标用户任务成功率或访谈结果。

## 要回答的问题

1. 目标用户能否完成“输入问题 → 定位来源 → 保存/导出卡片”？
2. 匹配线索的来源是否真能支持卡片判断？
3. 样本外问题会不会被误写成有来源的结论？

## 题集与标注

题集覆盖 21 道可回答题和 9 道资料外题；每题有预期证据 ID 或拒答标签、原文位置及[核对说明](annotation-notes.md)。题目来自对两篇公开论文的单人桌面核对，并非用户真实提问。题集已在本轮改进之前固定；改进时不修改题目和期望标签。运行命令：

```powershell
node evals/run.mjs baseline evals/results-baseline.json
```

脚本对可回答题要求**恰好一个结果且证据 ID 正确**，对资料外题要求零结果。逐题原始输出写入 JSON。此规则检索基线为 18/30，其中可回答题 10/21、资料外题 8/9；具体失败见[基线文件](results-baseline.json)。这些比率不能推断真实研究者使用效果。

## 指标口径

| 指标 | 计算与注意 |
| --- | --- |
| 任务成功率 | 目标用户在限定时间内正确找到来源并导出可核查卡片的任务数 / 完成的有效任务数；需记录人员、时长、任务和观察。 |
| 证据可核查率 | 经人工核对，来源定位正确且支持卡片关键判断的卡片数 / 被核查的卡片数。 |
| 错误断言率 | 卡片中出现来源不支持的关键事实的卡片数 / 被核查的卡片数。 |
| 无答案识别率 | 应拒答题中明确提示资料不足的题数 / 应拒答题数。 |
| 完成时间 | 从展示任务到成功导出或停止的秒数；区分成功和失败。 |

阈值待基线确定。此静态演示无模型调用，因此不报告模型成本、生成时延或“AI 准确率”。

离线指标另记：严格证据命中率 = 可回答题中恰好返回指定证据 ID 的题数 / 21；拒答率 = 资料外题中零结果的题数 / 9。它们与上表用户指标不混用。自动命中只能检查 ID，不能替代人工核查来源是否支持中文概述。

## 执行记录

每次程序测试须保留代码提交、题集版本、逐题输入/输出和错误分类。用户可用性测试还需单独记录匿名参与者、环境、任务、计时、观察与知情同意。后续应由独立标注者复核题集并增加真实用户问题。
