# 评价方案 v0.1（尚未执行用户评测）

## 要回答的问题

1. 目标用户能否完成“输入问题 → 定位来源 → 保存/导出卡片”？
2. 匹配线索的来源是否真能支持卡片判断？
3. 样本外问题会不会被误写成有来源的结论？

## 题集与标注

先以[草拟题集](questions.csv)覆盖可回答、不可回答、跨文献混淆、数字诱导题；每题记录预期文献 ID、原文位置、人工判定依据与是否需要拒答。公开题集仅是测试设计，不能当作已测结果。扩展至至少 30 条人工核对题后冻结题集版本；再跑基线与一次改进，保留逐题原始输出，不能为了提升分数改题。

## 指标口径

| 指标 | 计算与注意 |
| --- | --- |
| 任务成功率 | 目标用户在限定时间内正确找到来源并导出可核查卡片的任务数 / 完成的有效任务数；需记录人员、时长、任务和观察。 |
| 证据可核查率 | 经人工核对，来源定位正确且支持卡片关键判断的卡片数 / 被核查的卡片数。 |
| 错误断言率 | 卡片中出现来源不支持的关键事实的卡片数 / 被核查的卡片数。 |
| 无答案识别率 | 应拒答题中明确提示资料不足的题数 / 应拒答题数。 |
| 完成时间 | 从展示任务到成功导出或停止的秒数；区分成功和失败。 |

阈值待基线确定。此静态演示无模型调用，因此不报告模型成本、生成时延或“AI 准确率”。

## 执行记录

每次测试须新建日期化结果文件，含代码提交、题集版本、测试者（匿名）、环境、逐题输入/输出、人工判定、错误分类和原始时间。用户可用性测试需单独征得同意。当前没有运行结果文件，也没有访谈或试用结论。
