# research-evidence-workbench

AI4Science 研究证据助手｜AI 应用产品经理作品集

本项目旨在把科研文献检索、实验记录、证据整理与研究复现连接成可追溯的工作流程：从研究问题出发，保留文献来源和检索过程，记录实验条件，把结论关联到具体证据，并留下可检查的复现步骤。

> 当前阶段：项目骨架与记录规范。以下功能是计划建设的能力，尚未实现自动检索或分析服务。

## 主要功能方向

1. **文献检索与筛选**：保存检索词、数据库、检索日期、文献标识符和纳入或排除理由。
2. **实验记录**：记录研究假设、数据来源、代码版本、运行环境、参数与结果。
3. **证据整理**：让每条论断指向支持或反驳它的文献、数据或实验，并标注局限性。
4. **研究复现**：整理执行步骤、依赖版本、随机种子、预期结果和复现差异。

## 目录结构

```text
research-evidence-workbench/
├── README.md                 # 项目概览与开发计划
├── .gitignore                # 本地环境、敏感信息和生成物
├── docs/workflow.md          # 记录之间的关系与工作流程
├── templates/                # 四类研究记录模板
├── records/README.md         # 实际研究记录的存放约定
└── data/README.md            # 数据管理约定
```

## 开始使用

1. 阅读 [工作流程](docs/workflow.md)，确定研究问题和记录编号。
2. 从 `templates/` 复制相应模板到 `records/` 下的对应分类目录；首次使用时创建该目录。
3. 为文献、实验和证据填入来源链接与交叉引用；复现记录引用具体实验及代码版本。
4. 将可公开的文字记录纳入 Git；本地数据、密钥和生成物遵循 [数据管理约定](data/README.md) 与 `.gitignore`。

当前没有应用入口、自动化测试或依赖安装步骤；模板可以直接用 Markdown 编辑。

## 后续开发计划

- **阶段 1：记录验证**——用一个公开的小型研究问题试填四类模板，检查字段和引用关系。
- **阶段 2：检索辅助**——增加文献元数据导入、去重和筛选记录，保留原始来源与人工判断。
- **阶段 3：证据工作台**——按研究问题汇总证据、冲突结论和不确定性，支持从结论回溯原始记录。
- **阶段 4：复现工具**——增加最小可运行示例、环境锁定、结果对比和必要的自动化检查。

贡献或扩展前，请优先保持记录可追溯、数据使用合规，以及结论与证据之间的明确对应。
