# 本地最小演示

在仓库根目录运行：

```powershell
python -m http.server 8000
```

浏览器打开 `http://localhost:8000/app/`。需要 Python 3，不需要安装包、账号或 API Key。端口被占用时更换命令中的端口号。推荐用本地服务器打开，避免浏览器对 `file://` 的 JavaScript 模块限制。

试用路径：点击“BraTS 2023 模态”示例 → 查看来源并打开原文 → 选择来源 → 填写人工判断与局限 → 勾选已核对声明 → 保存 → 导出 Markdown。点击“无答案示例”可检查拒答路径。如果已经自行找到并核对一篇公开论文，可点击“手动登记已核对的公开来源”，填写标题、HTTPS 原文链接和章节/表格位置，再完成同一建卡流程。DOI、许可和备注可选；未确认许可时会标为“待核实”。手动条目以 `USER-` 开头，界面注明系统未核验。

现在内置两篇综述的 8 条人工概述。搜索是保守的规则匹配，不是自动文献检索或 AI 推理；它可能漏掉同义问法，也只覆盖这些固定材料。手动登记只校验字段和链接格式，不检查网页内容、许可或用户判断的真实性。卡片在当前浏览器 `localStorage` 中保存；没有服务端同步。输入问题和未保存的手动来源仅留在当前页面，刷新后会丢失。

示例来源、作者、许可与人工概述位置见[数据说明](../data/README.md)。勾选是创建者的自我声明，程序不能证明原文已经被阅读。演示不用于临床决策。
